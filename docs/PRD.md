# 「错因本」产品需求文档（PRD）

**版本：V1.0**
**产品形态：Android APK（100% Kotlin）**
**目标运行环境：HarmonyOS 4.x 及以下（AOSP 兼容层，Android 12 / API 31）**
**文档状态：初稿**


## 1. 文档说明

### 1.1 产品一句话定义

错因本是一款**以错因管理为核心**的学习工具：拍照 OCR 录题，不要求输入正解，只记录“为什么错”；考前按出错次数从高到低复习错因与对应题目，而不是看答案。

### 1.2 适用范围

本文档适用于：

- HarmonyOS 4.x 及以下版本设备；
- 通过 Android 兼容层安装和运行的 APK；
- 100% Kotlin + Jetpack Compose 技术栈；
- 不适用于 HarmonyOS NEXT / HarmonyOS 5.0+ / 6.0，因其已移除 AOSP 兼容层，无法运行 APK。

### 1.3 名词定义

| 名词 | 含义 |
|---|---|
| 错题 | 用户拍照或从相册导入的一道题目 |
| 错因 | 用户对“为什么错”的记录，可标签化、可统计 |
| 错因频次 | 某错因关联的错题次数，按降序排列 |
| 正解 | 正确答案。本产品中非必填，默认不录入 |
| 沙箱 | 应用私有目录，用户不可直接访问 |
| 指定目录 | 用户通过系统文件选择器选定的外部目录 |


## 2. 产品背景与定位

### 2.1 背景

传统错题本以“题目 + 答案”为核心，复习时容易变成重新看答案，效率低。实际考试前最有价值的信息是：**我总在哪些地方错、为什么错**。

错因本将错题本从“答案库”转变为“错因库”：

- 录题时只记录错因，不强制输入正解；
- 错因自动累计频次；
- 复习时先看题目，思考错因，再显示错因；
- 考前只看高频错因，不看答案。

### 2.2 产品定位

- **核心用户价值**：用最少输入，建立个人薄弱点画像。
- **差异化**：不围绕答案，围绕错因；不围绕单题，围绕频次。
- **使用场景**：日常作业/考试后录错题；考前冲刺复习。

### 2.3 产品目标

| 目标 | 说明 |
|---|---|
| 录题零负担 | 拍照 OCR，3 秒内可保存一道错题 |
| 错因可积累 | 错因标签长期复用，频次自动统计 |
| 复习高效率 | 考前按错因频次降序复习，不看答案 |
| 数据可导出 | 错因清单可导出到用户指定目录 |


## 3. 用户与场景

### 3.1 目标用户

- 中学生：数学、物理、化学、生物；
- 大学生：高数、线代、概率论、专业课；
- 考研/考证备考者：需要长期积累错因。

### 3.2 典型场景

**场景 A：日常录错题**
学生做完作业，发现一道数学题错了。打开错因本，拍照，OCR 识别题目，选择错因“计算错误”，补充备注“符号看错”，保存。全程不输入答案。

**场景 B：考前复习**
考试前晚，打开错因本首页，看到错因排行榜：
- 计算错误 23 次
- 审题失误 18 次
- 公式记错 12 次
点击“计算错误”，只看题目，先想“我为什么错”，再点“显示错因”。不显示答案。

**场景 C：导出错因清单**
考前把 Top 10 错因和代表题导出为 PDF，保存到手机指定目录，打印出来带到考场外复习。

## 5. 详细功能需求

### 5.1 录题模块

#### 5.1.1 拍照/相册

- 支持调用系统相机拍照；
- 支持从相册选择图片；
- 支持多张图片？MVP 单张，后续可扩展；
- 图片自动压缩，保存到应用沙箱。

#### 5.1.2 OCR 识别

- 使用 Google ML Kit 端侧文字识别；
- 支持中文、英文；
- 识别结果可编辑；
- 公式、图形不强行转文本，保留原图；
- OCR 失败时可手动输入文本。

#### 5.1.3 题目保存

字段：

| 字段 | 必填 | 说明 |
|---|---|---|
| 题目图片 | 是 | 沙箱路径 |
| OCR 文本 | 否 | 可编辑 |
| 科目 | 否 | 默认“未分类” |
| 来源 | 否 | 如“期中考试” |
| 备注 | 否 | 用户自由输入 |
| 正解 | 否 | 默认不显示、不要求 |
| 错因 | 是 | 至少一个 |

保存后，错因频次自动更新。

#### 5.1.4 保存到指定目录

- 录题时默认保存到应用沙箱；
- 导出时通过系统文件选择器让用户选择目录；
- 选择后持久化 URI 权限；
- 支持设置默认导出目录。


### 5.2 错因模块

#### 5.2.1 错因标签

- 预设错因：审题失误、计算错误、概念不清、公式记错、思路断、时间不够、单位漏看、抄写错误；
- 用户可自定义错因；
- 错因可分类：知识性、习惯性、策略性、心理时间；
- 错因可归档，归档后不再出现在快捷选择中，但历史统计保留。

#### 5.2.2 添加错因

- 录入题目时，键盘上方显示最近高频错因；
- 点选即关联；
- 支持多选；
- 支持新建错因；
- 支持备注具体错因，如“符号看错”。

#### 5.2.3 防重复与合并

- 新建错因时自动搜索相似项；
- 提示合并，例如“粗心”合并到“计算错误”；
- 支持重命名、合并、归档。


### 5.3 错因频次统计

#### 5.3.1 统计规则

- 每关联一次错因，计数 +1；
- 同一题可关联多个错因；
- 复习时点击“又错”，可再次增加对应错因计数；
- 默认按出错次数降序排列；
- 次数相同按最近出错时间降序。

#### 5.3.2 筛选

- 按科目筛选；
- 按时间范围筛选：近 7 天、近 30 天、全部；
- 后续支持时间衰减加权排序。


### 5.4 复习模块

#### 5.4.1 首页：错因排行榜

- 首页不是题目列表，而是错因排行榜；
- 每个错因显示：名称、出错次数、最近出错时间、关联题目数；
- 点击进入错因详情。

#### 5.4.2 错因详情页

- 展示该错因下所有题目缩略图/OCR 文本；
- **默认不显示答案**；
- 用户先思考“我为什么错”；
- 点击“显示错因”后展示错因和备注；
- 提供反馈按钮：记住了 / 又错 / 模糊。

#### 5.4.3 考前冲刺模式（V0.2）

- 取 Top 10 高频错因；
- 每个错因下抽取 3—5 道代表题；
- 生成“错因清单”；
- 支持导出 PDF/图片。


### 5.5 导出模块

| 格式 | 内容 | 优先级 |
|---|---|---|
| PDF | Top N 错因 + 代表题缩略图 | P0 |
| 图片 | 错因清单长图 | P0 |
| CSV | 结构化错因数据 | P1 |
| Anki | 正面题目图，背面错因 | P2 |

导出时：

- 调用系统文件选择器；
- 用户选择目录；
- 持久化权限；
- 写入文件；
- 提示成功或失败。


### 5.6 设置模块

- 科目管理：新增、重命名、删除；
- 默认导出目录设置；
- 数据备份与恢复（后续）；
- 清除数据；
- 关于与版本信息。

## 7. 数据模型（Room）

### 7.1 实体

```kotlin
@Entity(tableName = "subjects")
data class Subject(
    @PrimaryKey(autoGenerate = true) val id: Long = 0,
    val name: String,
    val sortOrder: Int = 0
)

@Entity(tableName = "questions")
data class Question(
    @PrimaryKey(autoGenerate = true) val id: Long = 0,
    val subjectId: Long?,
    val imagePath: String,
    val ocrText: String?,
    val note: String?,
    val source: String?,
    val saveDirUri: String?,
    val createdAt: Long,
    val mastered: Boolean = false
)

@Entity(tableName = "reasons")
data class Reason(
    @PrimaryKey(autoGenerate = true) val id: Long = 0,
    val name: String,
    val category: String?,
    val color: String?,
    val isArchived: Boolean = false,
    val createdAt: Long
)

@Entity(
    tableName = "question_reasons",
    foreignKeys = [
        ForeignKey(Question::class, ["id"], ["questionId"]),
        ForeignKey(Reason::class, ["id"], ["reasonId"])
    ]
)
data class QuestionReason(
    @PrimaryKey(autoGenerate = true) val id: Long = 0,
    val questionId: Long,
    val reasonId: Long,
    val detail: String?,
    val createdAt: Long
)

@Entity(tableName = "review_logs")
data class ReviewLog(
    @PrimaryKey(autoGenerate = true) val id: Long = 0,
    val questionReasonId: Long,
    val reviewedAt: Long,
    val result: String // remembered / wrong / fuzzy
)
```

### 7.2 核心查询

```sql
SELECT r.id, r.name, r.category,
       COUNT(DISTINCT qr.questionId) AS wrongCount,
       MAX(qr.createdAt) AS lastWrongAt
FROM reasons r
JOIN question_reasons qr ON r.id = qr.reasonId
JOIN questions q ON q.id = qr.questionId
WHERE q.subjectId = :subjectId
GROUP BY r.id
ORDER BY wrongCount DESC, lastWrongAt DESC;
```


## 8. 关键流程

### 8.1 录题流程

```
首页点击“+”
→ 拍照/相册
→ OCR 识别
→ 文本编辑
→ 选择/新建错因
→ 保存
→ 错因频次更新
→ 返回首页
```

### 8.2 复习流程

```
首页错因排行榜
→ 点击最高频错因
→ 看题目，不显示答案
→ 思考“为什么错”
→ 点击“显示错因”
→ 记住了 / 又错 / 模糊
→ 返回或继续下一题
```

### 8.3 导出流程

```
选择导出格式
→ 预览内容
→ 系统文件选择器
→ 用户选择目录
→ 持久化权限
→ 写入文件
→ 提示成功
```


## 9. 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 冷启动 ≤ 2 秒；录题保存 ≤ 3 秒；列表滚动流畅 |
| 离线 | OCR、数据库、复习全部离线可用 |
| 隐私 | 数据本地存储；不上传云端；导出由用户主动触发 |
| 兼容 | HarmonyOS 4.x 及以下；Android 12 / API 31 |
| 可用性 | 单手可操作；错因选择 3 秒内完成 |
| 存储 | 图片压缩；沙箱自动清理缓存；导出文件用户管理 |
| 安全 | 数据库可加密；导出目录持久化权限 |

## 12. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| HarmonyOS NEXT 无法运行 APK | 未来设备不可用 | 本版本仅限 4.x；后续评估迁移 |
| 公式 OCR 识别弱 | 数学题识别差 | 公式保留原图，不强行转文本 |
| 用户不写错因 | 统计失效 | 预设标签 + 一键选择，降低输入成本 |
| 错因重复 | 统计混乱 | 相似搜索 + 合并功能 |
| 导出权限失效 | 无法再次访问目录 | 持久化 URI 权限 |
| 华为纯净模式 | 安装 APK 受限 | 引导用户关闭纯净模式或允许安装 |


## 13. 验收标准

- 拍照后 3 秒内完成 OCR 并进入编辑页；
- 不输入正解也能保存错题；
- 错因可按出错次数降序排列；
- 复习时默认不显示答案；
- 点击“显示错因”后才展示错因；
- 可导出错因清单到用户指定目录；
- 应用在 HarmonyOS 4.x 设备上稳定运行。
